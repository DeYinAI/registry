# Conventional commits

See the full workflow in this plugin's skill. When committing:

1. Inspect `git status` and `git diff`.
2. Choose type (`feat`, `fix`, `docs`, `refactor`, `test`, `chore`, etc.) and optional scope.
3. Write an imperative summary under 72 characters.
4. Stage and commit when the user asks to apply the message.

Format: `<type>(<scope>): <summary>`
