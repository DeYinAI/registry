# Plugin template

Copy this folder to `plugins/<your-plugin-name>/` and edit:

1. `.deyin-plugin/plugin.json` — name, version, interface metadata, optional `variables`
2. `skills/<skill-name>/SKILL.md` — agent workflows
3. Optional: `commands/*.md`, `agents/`, `hooks/hooks.json`, `mcp.json`

Submit a pull request adding an entry to `registry.json` at the repo root.

See [../README.md](../README.md) for the full authoring guide.
